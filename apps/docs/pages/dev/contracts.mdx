# Local Development Contracts

import { HubContracts, SpokeContracts, NetworkOverview } from '../../components/ContractAddresses';

:::warning
These are **local development addresses** deployed to Anvil instances via the `pnpm deploy:crosschain` script. They only exist on your local chains — these are **not** testnet or mainnet addresses.

They are plain CREATE addresses (deployer + nonce), so they are deterministic only **from clean chain state**. Redeploying without restarting Anvil advances the deployer nonce and shifts every address.
:::

All contract addresses are pulled from `@swr/chains`. They update automatically when the package is updated after a new deployment.

## Spoke Contracts (Local Anvil — Chain 31338)

Spoke chains accept registrations locally and relay them to the hub via cross-chain bridge adapters. Each spoke deploys a SpokeRegistry, a FeeManager, a bridge adapter, and — when a `SOULBOUND_RECEIVER` is configured on the hub — a SpokeSoulboundForwarder for cross-chain soulbound mints. See [Hub-Spoke Architecture](/concepts/hub-spoke) for details on how cross-chain messaging works.
